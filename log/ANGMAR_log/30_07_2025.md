## General
- The general structure of ANGMAR is starting to take shape.

- It is still unclear how the final sensor configuration is to be determined.

## Parameters that needs determined
- Regularization parameter
- Grid resolution
- Number of new sensors

## Current algorithm concept
### Hyper parameters:
- Fix grid resolution at something low but feasible value in terms of computation, e.g. 20 km.

- Determine regularization parameter using real data from SuperMAG.
	- Addition of new sensors will change the optimal regularization, but that will be ignored for now.

### Optimal number of sensors:
- Run simulated annealing (SA) for multiple amounts of candidate sensors.

- Plot the minimum of the maximum resolution vs # of sensors.
	- Locate knee to determine the optimal amount of sensors
	- Test if greedy algorithm gives similar results.

### Final configuration - Idea 1
-  Run SA with optimal sensor amount.

- Grab the best configurations (some percentile)

- Create heat map of sensor placements

- Place 1 sensor at the "hottest" point.

-  Repeat process, but with one less movable sensor.
